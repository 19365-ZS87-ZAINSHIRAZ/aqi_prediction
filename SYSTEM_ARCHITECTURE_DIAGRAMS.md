## 4. Forecasting Module Architecture

```
┌─────────────────────────────────────────────────────────────────────────┐
│                         FORECASTING MODULE                               │
│                                                                          │
│  ┌────────────────────────────────────────────────────────────────┐    │
│  │                    Prophet Forecaster                           │    │
│  │                                                                 │    │
│  │  Input: Historical Data (180 days)                             │    │
│  │  ┌──────────────────────────────────────────────────────────┐ │    │
│  │  │ Step 1: Data Preparation                                  │ │    │
│  │  │  • Aggregate to daily averages                            │ │    │
│  │  │  • Remove outliers (3σ rule)                              │ │    │
│  │  │  • Fill missing dates (interpolation)                     │ │    │
│  │  │  • Format for Prophet (ds, y columns)                     │ │    │
│  │  └──────────────────────────────────────────────────────────┘ │    │
│  │                              ↓                                  │    │
│  │  ┌──────────────────────────────────────────────────────────┐ │    │
│  │  │ Step 2: Model Configuration                               │ │    │
│  │  │  • Daily seasonality: ON                                  │ │    │
│  │  │  • Weekly seasonality: ON                                 │ │    │
│  │  │  • Yearly seasonality: OFF                                │ │    │
│  │  │  • Changepoint prior scale: 0.05                          │ │    │
│  │  │  • Seasonality prior scale: 10.0                          │ │    │
│  │  │  • Interval width: 0.95 (95% confidence)                  │ │    │
│  │  └──────────────────────────────────────────────────────────┘ │    │
│  │                              ↓                                  │    │
│  │  ┌──────────────────────────────────────────────────────────┐ │    │
│  │  │ Step 3: Model Training                                    │ │    │
│  │  │  • Fit Prophet model on historical data                   │ │    │
│  │  │  • Learn trend components                                 │ │    │
│  │  │  • Learn seasonal components                              │ │    │
│  │  └──────────────────────────────────────────────────────────┘ │    │
│  │                              ↓                                  │    │
│  │  ┌──────────────────────────────────────────────────────────┐ │    │
│  │  │ Step 4: Forecast Generation                               │ │    │
│  │  │  • Create future dataframe (7 days)                       │ │    │
│  │  │  • Generate predictions                                    │ │    │
│  │  │  • Calculate confidence intervals                         │ │    │
│  │  └──────────────────────────────────────────────────────────┘ │    │
│  │                              ↓                                  │    │
│  │  Output: Forecasted Values (7 days ahead)                      │    │
│  │  • predicted_value                                              │    │
│  │  • lower_bound (2.5th percentile)                              │    │
│  │  • upper_bound (97.5th percentile)                             │    │
│  └────────────────────────────────────────────────────────────────┘    │
│                                                                          │
│  ┌────────────────────────────────────────────────────────────────┐    │
│  │                    ARIMA Forecaster                             │    │
│  │                                                                 │    │
│  │  ┌──────────────────────────────────────────────────────────┐ │    │
│  │  │ Step 1: Stationarity Check (ADF Test)                     │ │    │
│  │  │  • H0: Series has unit root (non-stationary)              │ │    │
│  │  │  • If p-value < 0.05: Stationary                          │ │    │
│  │  │  • If p-value ≥ 0.05: Needs differencing                  │ │    │
│  │  └──────────────────────────────────────────────────────────┘ │    │
│  │                              ↓                                  │    │
│  │  ┌──────────────────────────────────────────────────────────┐ │    │
│  │  │ Step 2: Order Selection (Grid Search)                     │ │    │
│  │  │  • Test p ∈ [0, 5], q ∈ [0, 5]                            │ │    │
│  │  │  • d = 0 if stationary, else d = 1                        │ │    │
│  │  │  • Select order with minimum AIC                          │ │    │
│  │  └──────────────────────────────────────────────────────────┘ │    │
│  │                              ↓                                  │    │
│  │  ┌──────────────────────────────────────────────────────────┐ │    │
│  │  │ Step 3: ARIMA(p,d,q) Model Fitting                        │ │    │
│  │  │  • AR(p): Autoregressive component                        │ │    │
│  │  │  • I(d): Integration (differencing)                       │ │    │
│  │  │  • MA(q): Moving average component                        │ │    │
│  │  └──────────────────────────────────────────────────────────┘ │    │
│  │                              ↓                                  │    │
│  │  ┌──────────────────────────────────────────────────────────┐ │    │
│  │  │ Step 4: Forecast Generation                               │ │    │
│  │  │  • Generate point forecasts                               │ │    │
│  │  │  • Calculate prediction intervals                         │ │    │
│  │  └──────────────────────────────────────────────────────────┘ │    │
│  └────────────────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────────────────┘
```
